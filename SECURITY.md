# Security policy

The maintenance focus is the current release and the default branch. Updates
and availability are best effort.

## Report a vulnerability privately

Use the repository's [private vulnerability report form](https://github.com/hrabosh/wos-mcp-bridge/security/advisories/new)
when enabled. Include the affected version, transport, impact and a minimal
reproduction with synthetic data. Remove API keys, tokens and any restricted
provider records from the report.

If the form is unavailable, open a GitHub issue asking the maintainer for a
private contact. Keep technical details and sensitive material out of the issue.
For an exposed API key, revoke or rotate it with the provider promptly.

Use ordinary [GitHub Issues](https://github.com/hrabosh/wos-mcp-bridge/issues)
for non-security bugs. Keep vulnerability details private while the maintainer
investigates and coordinates disclosure.
